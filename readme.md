# 互联网医疗行业调研分析报告

本项目是一份基于 HTML 制作的互联网医疗行业调研演示报告，内容涵盖行业演进、主要企业、典型业务场景及保险公司的健康管理策略。

## 项目结构

- `index.html`：报告页面及主要样式
- `deck-stage.js`：幻灯片播放、缩放和导航组件
- `imgs/`：报告中使用的图片资源

## 本地预览

直接使用浏览器打开 `index.html`，或在项目目录运行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 操作方式

- `←` / `→`、`PageUp` / `PageDown`：切换页面
- `Home` / `End`：跳转到首页或末页
- `R`：返回首页
- 浏览器打印：可将报告导出为 PDF
