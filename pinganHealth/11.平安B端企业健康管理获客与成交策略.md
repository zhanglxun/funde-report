# 平安B端企业健康管理获客与成交策略

> 延伸专题：[[12.平安B端采购续费与运营模式拆解]]

# 五、B端：平安如何向企业卖“保险+健康管理”

B端和F端的根本差别是：

| F端             | B端                   |
| -------------- | -------------------- |
| 决策者通常是个人／家庭    | 决策者是HR、行政、老板、工会、采购   |
| 买的是家庭保障与资源确定性  | 买的是员工福利、组织健康和成本管理    |
| 健康活动是获客和客户经营工具 | 健康活动是员工激活和服务交付工具     |
| 成交关键是家庭责任和养老焦虑 | 成交关键是福利竞争力、员工体验和费用可控 |

平安健康目前将企业产品组织成三类：

1. **健康委托管理**
2. **会员制健康管理服务**
3. **保险+**

并称之为“中国平安企业健康保障计划”。[平安健康业务介绍](https://www.jk.cn/businessIntroduction?bizMobilePage=businessModel)

---

## 1. 健康委托管理：企业买的是“健康福利的运营能力”

企业不是自己采购体检、问诊、心理、药品、健康讲座和保险，而是将一部分员工健康福利交给平安整合和运营。

通常包括：

- 员工健康测评；
- 体检前、中、后管理；
- 报告解读；
- 慢病风险分层；
- 家庭医生；
- 心理服务；
- 健康宣教；
- 就医绿色通道；
- 药品福利；
- 健康数据的汇总报告。

平安公开提到，企业端会为员工提供“检前、检中、检后”的管家式健康服务。[平安健康医险协同报道](https://www.yicai.com/news/102508678.html)

企业真正买的是：

> 不需要HR自己成为健康服务运营商，也能把分散福利变成一套可解释、可使用、可复盘的员工健康方案。

---

## 2. 会员制健康管理：给员工一个长期可调用的入口

其典型结构是：

- 员工获得家庭医生或线上医疗会员；
- 配套年度健康活动；
- 对慢病、高风险员工进行主动随访；
- 线上问诊、处方、购药；
- 线下体检、专科、心理等服务；
- 需要时进入医院、药店、居家服务网络。

企业活动在这里的功能不是现场卖单，而是：

- 提升员工权益知晓率；
- 激活服务使用；
- 完成健康档案；
- 找到高风险或高需求人群；
- 让企业看到福利被使用和员工满意度。

---

## 3. 保险+：把保障责任、健康账户和服务打包

平安对大中型企业公开提到的组合是：

> **商业保险 + 健康保障委托 + 医疗健康服务。**  
> [中国平安2023年中报](https://www1.hkexnews.hk/listedco/listconews/sehk/2023/0829/2023082901559_c.pdf)

对企业而言，这个组合可以拆为：

| 模块 | 企业买到的内容 |
|---|---|
| 商业保险 | 医疗、重疾、意外等保障责任 |
| 健康账户／委托管理 | 统一支付或预算管理员工健康福利 |
| 医疗健康服务 | 家庭医生、体检、就医、药品、心理、慢病等 |
| 服务运营 | 员工宣导、健康日、使用培训、数据复盘 |

平安健康披露，截至2024年末，其累计服务企业客户超过2,000家；企业健康管理收入占B端收入比重已明显提升。[平安健康2024年业务披露](https://health.people.com.cn/n1/2025/0318/c14739-40441398.html)

# 补充分析：B端获客与成交逻辑

对，**B端不能照搬F端“活动邀约—现场体验—个人成交”**的逻辑。

在B端，健康讲座、筛查、义诊、到企活动通常不是主获客手段，更不是成交现场；它们是：

> **签约后的服务交付、员工权益激活，以及续约证明。**

B端真正的销售，本质是一个“**大客户解决方案销售 + 团险/福利续约销售 + 服务运营证明**”的过程。

# 一、平安B端的基本打法：先拿企业账户，再运营员工

平安健康对企业端的产品概括为：

> **商业保险 + 健康保障委托 + 医疗健康服务**

并进一步拆成：

- 健康委托管理；
- 会员制健康管理服务；
- 保险+。[平安健康业务介绍](https://www.jk.cn/businessIntroduction?bizMobilePage=businessModel)

因此它不是先接触员工，再卖给企业；而是：

> 先说服企业HR、行政、工会、财务、采购或老板采购一套方案，再把员工变成服务用户。

```text
集团企业客户/市场线索
        ↓
企业决策层：HR、行政、财务、工会、采购、老板
        ↓
团险 / 健康福利 / 健康管理方案成交
        ↓
员工获得健康权益
        ↓
到企活动、体检、讲座、家医、药品、就医服务
        ↓
服务数据、满意度、理赔与健康报告
        ↓
续约、扩容、增加员工家属福利、交叉销售
```

# 二、平安B端主要从哪里获客

## 1. 平安集团已有企业客户：最重要的入口

平安最大的优势不是陌生拜访，而是集团本来就有企业关系：

- 团体保险客户；
- 平安银行对公客户；
- 产险企业客户；
- 企业主及高净值个人客户；
- 员工福利和补充医疗保险客户；
- 既有健康险、意外险客户；
- 平安代理人、银保及综合金融渠道接触的企业。

这意味着其典型销售动作不是：

> “我们有健康讲座，要不要办一场？”

而是：

> “您原来已经在平安买团险／补充医疗；我们能否把理赔、健康福利、员工服务和健康费用管理整合成一套？”

这是一种典型的**存量企业账户深耕**。

## 2. 团险续保与补充医疗保险招标

企业原本会采购员工意外险、团体医疗险、补充医疗险、高端医疗险、员工体检、工会福利和弹性福利。平安会在原有保险续保、招标或福利预算调整时，将单一保险升级为“保险+健康管理”方案。

| 企业原来的问题 | 平安要卖的升级方案 |
|---|---|
| 团险只有理赔，员工没感知 | 增加家医、问诊、购药、体检和就医协助 |
| HR处理员工理赔压力大 | 接入线上理赔、咨询助手和专属服务团队 |
| 医疗费用上涨、赔付不可控 | 做健康风险分层、慢病管理、理赔复盘 |
| 福利支出分散，难以管理 | 建健康账户或健康保障委托管理机制 |
| 员工觉得福利“看不见” | 到企活动、员工服务入口、可使用权益 |
| 续保只比价格 | 用服务网络、理赔时效和运营能力做差异化 |

所以，B端最常见的成交机会不是一场活动，而是：

> **原福利体系到期、成本上涨、员工满意度下降，或者HR希望把分散采购收归统一管理的时候。**

## 3. 大客户直销与关键人经营

| 角色 | 最关心的问题 |
|---|---|
| HR／人力负责人 | 员工体验、招聘留人、福利竞争力、管理负担 |
| 财务负责人 | 年度预算、医疗费用、成本可控性 |
| 采购 | 价格、合规、供应商能力、SLA |
| 工会／行政 | 活动是否可落地、员工是否愿意参与 |
| EHS／职业健康负责人 | 职业健康、员工风险、健康企业建设 |
| 企业老板／管理层 | 雇主品牌、组织稳定、员工生产力和风险 |
| 员工 | 好不好用、找谁、是否真能解决就医问题 |

# 三、B端如何促成：诊断—方案—试点—运营—续约

## 阶段1：企业健康福利诊断

平安需要先让企业看到现有体系的问题，包括员工结构、体检异常、理赔支出、慢病风险、福利使用率、员工满意度及HR服务压力。目标不是证明员工“不健康”，而是证明：

> 企业现在花的钱，没有有效变成员工感知，也没有形成健康风险和福利成本的管理能力。

## 阶段2：企业专属方案

按全员、核心员工、高管、慢病高风险人群、重疾员工及员工家属分层配置保险、家医、体检、心理、就医协助、慢病管理及高端医疗服务。平安卖给企业的不是一张权益卡，而是：

> **分人群、分场景、分预算的员工健康福利体系。**

## 阶段3：试点降低决策门槛

可在一个园区、事业部、地区分公司、高管群体或体检异常人群中，先开展筛查、报告解读、家医体验、慢病管理和健康日。试点考核的不是现场成交，而是到场率、建档率、激活率、家医使用率、高风险人群随访率和员工满意度。

## 阶段4：到企活动的真实作用

到企讲座、筛查和健康日的作用是：

1. 让HR证明福利被员工真正使用；
2. 让员工绑定健康账户、建立档案并激活线上服务；
3. 发现需要复检、慢病、心理和重疾就医支持的人群；
4. 为续约提供服务使用和满意度证据。

企业应获取脱敏、汇总的群体数据；个人健康信息应基于本人授权使用，不能直接变成保险推销线索。

## 阶段5：运营与续约

企业客户续约时，销售不应只给下一年报价，而应提交年度价值报告：覆盖员工数、权益激活率、服务使用量、体检异常复核、理赔效率、满意度、健康风险变化、HR工作负担变化及下一年升级模块。

> B端真正的护城河不是首次成交，而是健康档案、服务入口、员工使用习惯、HR运营流程、年度报告和续约数据。

# 四、对富德最重要的启发

富德的B端健康活动不应定义为“企业版销售会”，而应定义为：

> **企业健康管理解决方案的交付和证明环节。**

更合理的路径是：

```text
已有企业关系 / 团险续保 / 企业主资源 / 招投标
        ↓
HR与财务的福利、成本、员工体验诊断
        ↓
商业保险 + 健康账户/委托管理 + 医疗健康服务方案
        ↓
小范围试点或年度健康活动
        ↓
员工权益激活、建档、线上服务使用
        ↓
季度/年度健康与服务运营报告
        ↓
续约、扩容、员工家属及高管方案升级
```

最关键的认知转变是：

> F端活动里，健康筛查是“个人客户的需求入口”；  
> B端活动里，健康筛查是“企业服务能力的交付证明”。

所以B端成交的对象不是员工的健康焦虑，而是企业对三件事的支付意愿：

1. **员工福利是否有竞争力；**
2. **健康和医疗成本是否可管理；**
3. **HR是否能少做琐事、又拿得出成果。**

# 五、B端核心价值：企业到底在买什么，如何设计、传递与包装服务价值

## 1. 一句话定义

企业表面采购的是团险、体检、问诊、健康活动或员工福利；但企业真正购买的是：

> **一套可被员工感知、可被HR运营、可被财务管理，并能在员工生病时真正履约的健康福利基础设施。**

因此，B端产品不是“把若干健康权益打包卖给企业”，而是把企业原本分散、低感知、难管理的医疗健康福利，变成一个有统一入口、有服务责任人、有支付机制、有运营数据的员工健康管理系统。

---

## 2. 企业、HR、员工分别在买什么

B端不是一个用户，而是三层用户共同决定采购是否成立。

| 角色       | 表面需求      | 真正购买的价值                    |
| -------- | --------- | -------------------------- |
| 企业老板／管理层 | 员工福利、雇主品牌 | 组织稳定、人才吸引与保留、风险可控、管理层安心    |
| HR／行政／工会 | 落地员工关怀    | 少做琐事、有可交付成果、员工少投诉、服务商能兜底   |
| 财务／采购    | 预算和合同     | 支出可控、责任清楚、价格合理、服务可量化、合规可审计 |
| 员工       | 保险与健康权益   | 生病时有人管、日常用得上、少跑腿、少垫钱、少焦虑   |
| 员工家属     | 家庭健康支持    | 获得可调用的医疗资源与照护支持            |

所以，不能只向企业讲“我们有多少项服务”，而应同时回答四个问题：

1. 对老板：这项投入如何让组织更稳定、更有吸引力？
2. 对HR：谁来把服务真正运营起来，而不是把工作又交回给HR？
3. 对财务：钱花在哪里、怎样控制、如何证明效果？
4. 对员工：我什么时候能用、找谁用、出了问题谁负责？

---

## 3. 企业购买的五项核心价值

### 价值一：把“出险后赔钱”升级为“日常有人管”

传统团险是低频、被动的：员工生病后理赔，企业才感知服务发生。

健康管理产品把服务前置到：

- 体检前后的健康管理；
- 日常问诊与健康咨询；
- 慢病随访与复查提醒；
- 心理支持；
- 用药与就医协助；
- 重疾后的专案管理。

企业买到的不是更复杂的保险，而是把员工医疗健康问题从“出事后处理”变成“日常可管理”。

### 价值二：把分散福利变成一个统一入口

企业往往已分别采购体检、团险、心理服务、工会福利、医务室、药品补贴等，但员工找不到入口，HR也难以协调。

产品价值在于把这些资源收进：

- 一个员工服务入口；
- 一个健康账户或支付机制；
- 一个服务团队；
- 一套员工运营节奏；
- 一份企业健康运营报告。

> 企业买的是“福利整合和运营能力”，不是又增加一个供应商。

### 价值三：让员工真正感知福利

很多企业福利的问题不是预算少，而是员工无感：不知道、不会用、想用时找不到。

到企筛查、健康讲座、体检报告解读、家庭医生首访和员工健康日的作用，是让抽象权益变成一次真实服务体验，再把员工导入长期服务入口。

员工对福利的感知，最终取决于三个瞬间：

- 日常小问题能否迅速咨询；
- 体检异常后是否有人跟进；
- 重疾、住院或理赔时是否有人把事情办下来。

### 价值四：降低HR的事务成本和服务风险

HR真正担心的往往不是“有没有健康讲座”，而是：

- 员工生病、理赔、投诉时谁处理；
- 服务商是否响应；
- 多地员工的服务是否一致；
- 福利项目是否被使用；
- 年底是否能向老板解释预算价值。

因此产品必须明确提供：专属客户经理、员工服务入口、标准服务时效、异常升级机制、活动执行、季度报告和年度复盘。

> 对HR而言，最有价值的产品不是权益最多，而是“有问题时有人接、有人办、有人给结果”。

### 价值五：让健康福利支出更可控、更可解释

企业并不一定期待健康管理短期直接降低医疗费用；它更需要看清支出、提升福利使用效率，并避免重疾、慢病、理赔和员工投诉带来的不确定性。

可被企业感知的管理价值包括：

- 团险和补充医疗的理赔数据复盘；
- 员工健康风险的脱敏汇总；
- 高风险人群的服务覆盖；
- 健康账户和服务预算的使用情况；
- 服务使用率、满意度和时效；
- 下一年度的福利优化建议。

---

## 4. 产品设计：不要做“权益大礼包”，要做“三层产品架构”

建议将B端产品设计成“保障层 + 服务层 + 运营层”，而不是将大量单项权益堆在一张清单上。

| 产品层 | 客户买到什么 | 核心模块 |
|---|---|---|
| 保障层 | 风险发生时的支付保障 | 团体医疗、意外、重疾、高端医疗、补充医疗 |
| 服务层 | 日常健康和就医问题的解决能力 | 家庭医生、体检、心理、慢病、购药、就医协助、重疾专案 |
| 运营层 | 企业福利可管理、可交付、可复盘 | 员工激活、到企活动、专属服务团队、健康看板、季度/年度报告 |

### 基础版：全员可感知

适合预算有限或首次合作企业。重点不是“低价”，而是建立统一入口和使用习惯：

- 在线问诊；
- 健康测评；
- 基础健康活动；
- 体检报告解读；
- 药品福利或购药服务；
- 基础团险；
- 员工服务入口与运营触达。

### 进阶版：健康管理闭环

适合已有团险、希望提升员工体验和健康管理能力的企业：

- 家庭医生；
- 检前、检中、检后管理；
- 慢病和高风险人群随访；
- 心理健康服务；
- 就医协助；
- 健康账户／委托管理；
- 季度健康报告与企业健康日。

### 高端版：核心人才与高管健康保障

适合总部、高管、核心人才及高价值人群：

- 高端医疗；
- 专家咨询与二次诊疗意见；
- 专家门诊、住院和重疾专案协助；
- 家属扩展方案；
- 高端体检、抗衰或康复服务；
- 高管专属健康顾问；
- 异地、海外或特需医疗资源衔接。

关键原则：**全员有基本获得感，重点人群有明确升级路径，企业有清楚的预算边界。**

## 5. 服务价值如何传递：从“权益说明”改为“场景承诺”

不建议对企业或员工主讲：

> 我们有50项服务、2000家机构、100场活动。

这类信息只能证明资源多，不能说明对用户有什么用。

应改为围绕企业与员工真实场景传递价值：

| 场景 | 应传递的服务价值 |
|---|---|
| 员工体检异常 | 有人解读、有人回访、有人协助复检，而不是只给一份报告 |
| 夜间小病或孩子发烧 | 能快速找到医生，知道是否需要去医院 |
| 慢病员工复诊配药 | 有持续提醒、咨询和购药支持，减少员工请假与奔波 |
| 员工确诊重疾 | 有人协助找科室、找医院、安排复检和住院，并衔接理赔 |
| HR面对员工咨询或投诉 | 有统一入口、服务时效和升级机制，不需要HR逐一协调 |
| 年度福利复盘 | 有使用数据、满意度与优化建议，可以向管理层交代成果 |

产品表达应从“我们提供什么”转成：

> **员工遇到什么问题，我们在多长时间内，由谁，用什么方式帮他解决。**

## 6. 如何包装为企业愿意付费的方案

### 对老板：包装成“人才与组织健康投资”

核心表达：

> 不是多一项福利成本，而是让员工在关键时刻感受到企业关怀、让核心人才更愿意留下的基础设施。

### 对HR：包装成“员工关怀运营外包”

核心表达：

> 企业不需要自己组建医疗服务团队；我们负责员工触达、权益激活、活动执行、咨询承接、异常升级和数据复盘，HR只需看结果。

### 对财务和采购：包装成“可控预算下的一体化方案”

核心表达：

> 不把钱分散花在多个低使用率项目上，而是以清楚的保障、服务和运营模块配置预算，并以服务数据和年度报告评估投入产出。

### 对员工：包装成“你和家人随时能用的健康支持”

核心表达：

> 不只是公司替你买了一份保险；你遇到健康、就医、用药和体检问题时，有一个能马上找到、有人负责的服务入口。

## 7. 销售方案中必须呈现的五项证据

要让企业为服务价值付费，方案中至少应展示：

1. **服务地图**：员工在何时、从哪里进入服务；线上、医院、药店、到企与到家如何衔接。
2. **服务SLA**：咨询、报告解读、异常升级、就医协助、理赔支持分别由谁响应、多久反馈。
3. **本地履约能力**：企业所在地的医院、体检、药店、活动和服务商覆盖情况。
4. **运营机制**：员工如何激活、如何触达、活动如何执行、HR如何获得支持。
5. **年度价值报告样例**：覆盖率、激活率、使用率、满意度、服务时效、风险人群服务覆盖及优化建议。

没有这五项，健康管理容易被企业理解为“保险赠品”或“可有可无的活动”；具备这五项，才能被理解为可采购、可考核、可续约的企业服务能力。

## 8. 最终产品定位

对外最有效的定位不是“企业健康管理平台”，而是：

> **企业员工健康福利运营解决方案。**

再进一步，可把价值主张压缩为一句话：

> **让员工日常健康有人管、关键就医有人办、企业福利有人运营。**

这句话同时覆盖了员工、HR和企业管理层的核心价值，也是产品、服务、销售材料和到企活动应共同传递的主线。
