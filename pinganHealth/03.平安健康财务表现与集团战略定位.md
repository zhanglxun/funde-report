
# 平安健康（平安好医生）在中国平安集团财报中的业绩表现深度调研分析

## 结论先行

- **平安健康已从"烧钱的互联网医疗第一股"转型为平安集团"医疗养老生态圈"的盈利旗舰**：据《经济参考报》（新华社，2026年3月26日）引平安健康2025年报，"2025年，公司实现总收入54.68亿元，同比增长13.7%；录得归母利润3.8亿元，同比增长366.1%；调整后净利润4.14亿元，同比增长161.3%"，并自2024年底起并入平安集团合并报表；但其收入体量仅相当于集团1.05万亿营收的约0.5%，战略价值远大于财务贡献。
- **收入结构已彻底从C端消费医疗转向F端（商保协同）+B端（企业健管）**：2025年F端收入32.96亿元（约占60%）、B端13.06亿元（占比23.9%、+40.6%），高度依赖平安集团导流——2025年五大客户（全部为平安子公司）约占总收入40%，独立获客能力仍是核心风险。
- **集团层面将医疗养老明确定位为"第二增长曲线"**：据第一财经报道（经新浪财经转载，2026年3月），"'医疗养老'贯穿在中国平安2025年年报的各个部分，被提到了65次；相关战略阐述篇幅达12页，较2024年翻倍"；管理层强调其"差异化赋能金融主业"，而非追求板块本身的利润规模。

## Key Findings

1. **结构性变化**：平安健康（原平安好医生）2024年通过大股东安鑫"以股代息"将持股由39.41%提升至52.74%，触发62.83亿港元强制全面要约，自2024年底起纳入平安集团合并报表，成为间接非全资附属公司。集团明确表示"无意私有化"。公司收入从2021年峰值73.34亿元的C端消费医疗模式，收缩重构为2023年的46.74亿元低点，再在F端+B端驱动下于2024–2025年回升至48.08亿、54.68亿元。
    
2. **集团大盘定位**：平安健康在集团财报中被归入"医疗养老生态圈"（2024年前称"医疗健康生态圈"），与北大医疗集团并列为两大"自营旗舰"。其收入/利润未作为独立分部在集团利润表中单列，而是以"赋能主业"的隐性价值呈现。据中国平安2025年报（中新网，2026年3月27日），"北大医疗集团营业收入…2025年达57.23亿元；平安健康…2025年实现营业收入54.68亿元，净利润3.80亿元"，二者合计约112亿元，仅占集团营业收入10505亿元的约1.1%。
    
3. **盈利模式**：平安健康2024年首次全年盈利，2025年连续两年盈利且经营利润首次年度转正（约1亿元）。盈利驱动是"控成本、增收入"：费用率从2023年的高位大幅下降，AI降本叠加F端/B端高毛利业务放量。
    
4. **宏观战略定位**：集团在2025年报中表述"医养服务正加速成为平安第二增长曲线"，副总经理兼CFO付欣称医养战略处于"三步走"的第二阶段关键期。马明哲的经典论断"金融是平安的现在时，医疗是平安的未来时"被反复引用。
    
5. **业绩质量**：收入可持续性的疑点在于对集团关联渠道的高度依赖（五大客户全部为平安子公司、约占收入40%），F端增长主要来自集团2.5亿个人客户的内部导流；B端（企业健管）是增速最快、市场化程度相对更高的板块。
    

## Details

### 一、结构性变化：从"互联网医疗第一股"到"集团并表旗舰"

**（1）私有化/整合进程**

平安健康2018年5月4日于港交所上市（股票简称"平安好医生"，2021年前后启用"平安健康"公司名），2020年7月纳入恒生科技指数。整合进程的关键节点是2024年底：

- 2024年11月，平安健康宣布派发每股9.7港元的特别股息（分红总额约108.5亿港元）；
- 大股东安鑫有限公司（平安集团间接全资拥有）选择"以股代息"，触发《收购守则》规则26项下的强制性无条件现金要约。安鑫控制股份由4.41亿股（约39.41%）增至约11.4亿股（约52.74%），要约最高现金对价约62.83亿港元；
- 交割后（2025年1月），平安健康成为平安集团间接非全资附属公司，**财务业绩并入平安集团合并报表**；
- 集团在联合公告中明确："无意私有化公司且认为不存在私有化的合理可能性"，即保持独立上市运营。

2025年3月的2024年报业绩发布会，是平安健康首次以"平安集团并表子公司"身份召开。

**（2）收入结构变化：C端→F端+B端**

历史营收轨迹清晰显示战略切换的代价与成果（单位：人民币）：

|年度|总收入|同比|净利润/亏损|
|---|---|---|---|
|2018|33.38亿|—|亏9.13亿|
|2019|50.65亿|—|亏7.47亿|
|2020|68.66亿|—|亏9.49亿|
|2021|73.34亿（峰值）|—|亏15.39亿|
|2022|约61.6–62.05亿|-16%|亏6.11亿|
|2023|46.74亿|-24.7%|亏3.35亿|
|2024|48.08亿|+2.9%|盈0.88亿（调整后1.58亿）|
|2025|54.68亿|+13.7%|盈3.80亿（调整后4.14亿）|

据证券时报网（stcn.com，2025年3月）引平安健康2024年报，"2024年公司录得总收入48.08亿元，同比增长2.9%…实现净利润0.88亿元，较上年亏损3.35亿元实现扭亏为盈，调整后净利润1.58亿元。这也是公司首次实现全面盈利"。

峰值时期（2021年）收入主要来自C端消费医疗（在线问诊+健康商城/消费型健康服务）。战略2.0（2022年启动）主动去化"低战略协同性业务"（主要为C端），2022–2023年营收连续两年大幅下滑，员工从2021年的3425人降至2023年的1753人（近乎腰斩）。此前近10年公司累计亏损约72亿元。

转型后形成"3+2+3"模式：以F端（金融/综合金融客户端）、B端（企业端）、C端为三大支付端，整合供应方，打造"家庭医生""养老管家"两大服务枢纽。

- **F端（商保协同）**：2024年收入约24.17亿元（+9.6%，ARPU同比+17.6%，旧口径）；2025年按"商保协同"口径收入32.96亿元（+11%），约占总收入60%。F端付费用户2025H1达约2000万人（+34.6%）。
- **B端（企业健管）**：2024年收入约14.3亿元（+32.7%），付费用户581万人（+13%），企业客户2049家（+35.9%）；2025年收入13.06亿元（+40.6%，口径调整），营收占比升至23.9%（+4.6pp），企业客户突破6700家（+83.1%），贡献GMV约36.3亿元。
- **养老服务**：2024年收入2.83亿元（+413.5%）；2025H1养老业务收入同比增长263.9%（低基数高增速）。

按旧业务分类（2024年报），三大板块为：医疗服务21.69亿（+4.9%）、健康服务23.56亿（-7.6%，主要为C端商城萎缩）、养老服务2.83亿（+413.5%）。

**（3）用户/付费/渠道结构变化**

- 整体付费用户：2024年约3140万人；2025H1整体付费用户同比+35.1%。
- 渠道高度集中于集团F端导流：F端服务覆盖平安集团约2.45亿个人金融客户；家医权益用户2024年超1400万、2025H1超2000万。
- 2024年管理层披露：付费用户在集团2.4亿个人客户中渗透率仅约13%；B端企业客户在集团企业客户中渗透率仅约3%——即协同空间大但基数依赖集团。

### 二、在集团大盘中的定位

**（1）归类与披露位置**

平安集团财报中，医疗健康业务归入"医疗养老生态圈"（2024年前称"医疗健康生态圈"，体现"医疗健康"向"医疗养老"的战略升维）。平安健康被表述为"平安集团医疗养老生态圈的旗舰和入口""管理式医疗模式的重要组成部分"，与北大医疗集团并列为两大"自营旗舰"。

**（2）营收/利润占比**

关键事实：**平安健康的收入/利润并未作为独立分部在集团合并利润表中单列**，集团主要通过"赋能主业"的口径披露医养生态价值。就直接财务贡献而言：

- 2025年平安健康营收54.68亿、净利3.80亿；北大医疗营收57.23亿。
- 二者合计约112亿元，占集团2025年营业收入10505.06亿元约1.1%；平安健康单独占比约0.5%。
- 相比之下，寿险及健康险、财产险、银行三大金融主业才是利润主体（集团2025年归母营运利润1344.15亿）。

这说明医养板块对集团的意义**不在于自身营收利润规模，而在于对保险主业的差异化赋能**。

**（3）管理层战略表述**

- 马明哲2025年报董事长致辞：深化"综合金融+医疗养老"双轮并行、科技驱动战略；经典论断"金融是平安的现在时，医疗是平安的未来时"。
- 2026年集团确立"服务年"为核心主题，以"四到"（到线、到院、到家、到企）服务网络为支撑。

### 三、盈利情况与模式表述

**（1）扭亏为盈时间点**

- 2024H1：首次半年度盈利（净利超6000万、调整后近9000万）。
- 2024全年：首次全年盈利（净利0.88亿、调整后1.58亿），经营性现金流首次转正。
- 2025全年：连续两年盈利，经营利润首次年度转正（约1亿元）。

**（2）盈利驱动因素**

- 控成本：2024年费用总额同比下降6.23亿元，整体费用率降至35.2%（同比-14.4pp）；2024H1费用率同比降17.9pp。
- AI降本：据腾讯新闻报道中国平安2025年报（2026年5月），"2025年，中国平安AI坐席服务量约17.02亿次，覆盖了80%的客服总量，第四季度单次问诊成本同比下降45%"；AI医生"辅助诊疗准确率95.1%，年使用人数近1200万"，覆盖集团100%个人客户；AI贡献毛利占比2025年约4.5%、2026H1约4.6%。
- 增收入：F端稳健+B端快速放量的高毛利业务结构优化。

**（3）与保险主业协同**

- CEO表述："双向赋能"——为集团金融客户提供医养服务，同时提升保险产品差异化竞争力。
- 量化协同：据中国平安2025年报官方通稿（pingan.com，2026年3月），"2025年使用医养服务的客户加保率提升4个百分点；医疗健康权益客户寿险新单件均提升至1.5倍；居家养老权益客户寿险新单件均提升至5.2倍；高品质养老权益客户寿险新单件均提升至23.4倍"。

### 四、宏观战略定位

- 2025年报明确："医养服务正加速成为平安第二增长曲线"；据第一财经，"'医疗养老'贯穿在中国平安2025年年报的各个部分，被提到了65次；相关战略阐述篇幅达12页，较2024年翻倍"。
- 据第一财经专访（2026年3月），中国平安副总经理兼首席财务官付欣称，"医疗养老战略发展分为三个阶段，目前正处于第二阶段的关键期。预计未来两至三年，能够进入独立产生轻资本消耗收入的第三阶段…内部目标是希望到2028年能看到爆发式的成效"。
- 集团层面医养生态赋能：2025年使用医养服务客户加保率提升4个百分点；居家养老权益客户寿险新单件均提升5.2倍；高品质养老权益客户提升23.4倍。
- 据腾讯新闻报道（2026年3月31日），"截至2025年9月末，在平安近2.5亿个人客户中，有近63%同时享有医疗养老生态圈"服务权益，这些客户贡献寿险新业务价值的近70%；另据中国平安2025年报，平安寿险使用医疗养老服务客户数达1829.8万人。

### 五、业绩质量与分布

**（1）收入质量与关联交易**

- 关联交易集中度高：据平安健康2025年报"主要客户"披露，公司五大客户全部为平安集团子公司（平安人寿、平安产险、平安银行、平安健康险、平安养老险），合计约占总收入40%，最大单一客户约占16.3%。历史上（2021–2023年）来自平安关联方的收入约占37%/37%/33%（据DoNews引年报），2025年有所回升。
- 双向关联：平安健康既向集团取得收入，又向集团采购服务（2021–2023年服务采购分别为4.92亿、4.62亿、5.62亿元；2024–2025最新精确金额需查阅港交所年报"持续关联交易"章节财务附注，本报告不臆测）。
- 可持续性隐忧：F端增长高度依赖集团内部导流，若脱离集团资源"输血"，独立增长能力待观察；B端市场化程度相对更高，被视为长期核心增长驱动。

**（2）区域/渠道分布**

- 渠道高度集中于集团综合金融渠道（寿险、产险、健康险、银行），以寿险代理人渠道导流为主。
- 居家养老服务2025年覆盖全国100城（2026H1达140城），获得服务资格客户超24万人（2026H1超31万）。

**（3）增长率数字汇总**

_平安健康（2025年报）_：总收入+13.7%；归母净利+366.1%；调整后净利+161.3%；F端+11%；B端+40.6%（企业客户+83.1%）。

_平安健康（2026H1，最新一期）_：总收入24.84亿元（同比-0.7%，首次同比微降）；归母净利2.19亿（+63.5%）；调整后净利2.27亿（+37.7%）；F端15.84亿（基本持平）；B端7.14亿（+65.1%，占比28.7%、+11.5pp）；付费企业客户超7700家（+73%）。

_平安集团（2025年报）_：营业收入10505.06亿（+2.1%）；归母营运利润1344.15亿（+10.3%）；归母扣非净利1437.73亿（+22.5%）；寿险健康险NBV 368.97亿（+29.3%）。

_平安集团（2026H1）_：营业收入5751.38亿（+15.0%）；归母净利925.85亿（+36.1%）；归母营运利润841.96亿（+8.3%）。

## Recommendations

1. **投资/研究视角——把平安健康当作"集团协同期权"而非独立成长股来估值**：其约60%收入来自F端集团导流、五大客户皆为集团子公司，独立性折价应纳入模型。**触发重估的关键指标**：B端企业客户数与B端收入占比（2026H1已达28.7%）、非集团支付方收入占比、F端付费用户在集团2.5亿客户中的渗透率能否从约13%持续抬升。
    
2. **关注2026H1的收入首次同比微降信号**：2026上半年总收入24.84亿元同比-0.7%，是转型以来首次收入负增长（利润仍高增，主要靠B端+65.1%对冲F端持平及"其他"收入下滑）。需跟踪是F端结构调整的短期扰动，还是集团导流红利见顶。若2026全年收入无法恢复正增长，"第二增长曲线"叙事将受挑战。
    
3. **跟踪治理与管理层变动**：2026年8月朱友刚获委任董事会主席（此前主席/CEO为李斗，CEO一度由何明科担任），近两年管理层更迭密集（王涛→方蔚豪→李斗），需评估战略连续性。
    
4. **验证"第三阶段"承诺**：CFO付欣称未来2–3年（内部目标2028年）进入"轻资本消耗、独立产生收入"的第三阶段——以经营利润率、经营性现金流、B端市场化收入为验证基准。若届时仍高度依赖集团关联交易（约40%），则战略兑现存疑。
    

## Caveats

- **数据来源与口径**：核心数据来自平安健康2025年报（2026年3月）、2026年中报（2026年8月），及中国平安2025年报、2026年中报；辅以《经济参考报》（新华社）、第一财经、财新、界面、澎湃、21世纪经济报道、证券时报等媒体。不同报道对F端/B端收入口径存在差异（如2024年F端有24.17亿旧口径与约29.69亿重述口径并存），已尽量标注。
- **未直接披露项**：平安健康2024/2025年向平安集团的服务采购精确金额，需查阅港交所年报"持续关联交易"财务附注补全，本报告未臆测；2024年关联方收入占比精确数字亦未在公开材料中查得。
- **集团层面无独立分部**：平安集团合并报表未将医疗养老/平安健康作为独立利润分部单列，故"占集团营收/利润比重（约0.5%–1.1%）"为基于公开营收数据的估算，非集团官方分部披露。
- **预测性表述提示**："第二增长曲线""三步走进入第三阶段（2028年爆发）""B端成为长期核心驱动"等均为管理层前瞻性表述或媒体判断，非已实现事实。
