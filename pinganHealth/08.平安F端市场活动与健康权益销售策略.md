# 平安F端市场活动与健康权益销售策略

## 先给结论

平安也会做你说的这类**线下健康筛查、讲座、客户沙龙、健康节、养老体验活动**，而且依托寿险分公司、支公司、代理人、银行网点、健康服务商来落地。公开资料显示，平安曾在全国组织百场健康主题体验活动，包括中医问诊、经络诊断、仪器检测和健康主题沙龙等。[中国平安“99健康节”说明](https://www.pingan.cn/m/common/news/article/1694575018662.shtml)

但它的理想打法不应停在：

> 检测发现风险 → 制造焦虑 → 当场卖保险。

而是把现场活动定义为**服务权益的体验入口**，后续用家庭医生、金管家App、就医协助、养老管家等持续履约，让用户感到：

> 我买的不是一次检查，也不是一张“权益清单”；而是未来遇到健康、就医、养老问题时，有一个长期可调用的人和网络。

平安销售更高客单保单的关键，不在筛查设备本身，而在于将其包装、兑现为一套“**保险保障 + 会员身份 + 家庭服务网络**”的长期方案。

# 一、平安线下活动的组织方式：不是单一网点，而是一套协同网络

## 1. 谁组织

典型参与方包括：

| 角色            | 主要任务                   |
| ------------- | ---------------------- |
| 寿险分公司、支公司、营业区 | 场地、客户运营、活动执行、保单承接      |
| 保险代理人         | 邀约客户、家庭需求访谈、活动后跟进      |
| 平安银行、证券等金融网点  | 联合邀约高净值或存量金融客户         |
| 平安健康／平安好医生    | 家庭医生、健康档案、线上服务、就医资源承接  |
| 医疗、体检、养老服务商   | 检测、咨询、体验和线下履约          |
| 集团品牌活动        | 如“99健康节”、养老服务发布、客户回访活动 |

平安公开描述过由寿险、产险、银行、健康险、平安健康多家公司共同参与的健康活动；这意味着它不是单靠寿险网点卖服务，而是用集团客户池和医疗养老资源共同承接。[中国平安健康节活动说明](https://www.pingan.cn/m/common/news/article/1694575018662.shtml)

---

## 2. 线下活动通常服务于三类目标

### A. 存量客户经营

不是只为“卖首单”，而是为：

- 保单回访；
- 客户家庭成员信息补全；
- 激活既有医疗健康权益；
- 识别父母养老、子女医疗、客户自身慢病等新需求；
- 推动加保、续保或产品升级；
- 获取转介绍。

平安人寿已有把代理人定位为“**金融顾问、家庭医生、养老管家**”三类价值传递者的公开表述，并以线下居养体验、财富论坛、教育沙龙、权益发布会等做客户经营场景。[平安人寿安徽分公司客户回访活动](https://ah.people.com.cn/n2/2024/1021/c227767-41014635.html)

### B. 高价值客户的服务资格展示

尤其是：

- 储蓄险、终身寿险、年金险客户；
- 中高净值客户；
- 有父母养老压力的40—60岁客群；
- 已有重疾、慢病、医疗资源焦虑的家庭。

这类活动的重点不是展示“眼底仪很厉害”，而是展示：

- 有健康风险时，家庭医生能否给建议；
- 需要住院时，谁帮忙安排；
- 父母居家养老时，谁响应；
- 家庭成员能否共享部分服务；
- 服务是不是可以在本地真正使用。

### C. 新客获客与代理人增员／转介绍

健康讲座、义诊、公益筛查最适合降低首次接触门槛。用户愿意因为“免费或公益健康服务”进入场景；但真正成交往往发生在之后的一对一家庭保障分析、养老方案沟通和服务权益讲解中。

---

# 二、平安与富德这类活动最关键的差异，应该在哪里

你描述的富德现场活动，核心问题并不是筛查本身，而是用户的感知链路容易变成：

> 你让我做检测 → 检测多少有问题 → 你告诉我风险很大 → 你向我卖保险。

这样，健康筛查是一个**促成工具**，用户也会把“健康管理服务”理解为保险销售的包装。

平安若要把活动做成高价值服务，关键是把逻辑倒过来：

| 低价值的活动逻辑 | 高价值的平安式逻辑 |
|---|---|
| 发现问题，促进投保 | 先让客户感知未来问题有人负责 |
| 一次性筛查 | 筛查—解读—转诊—跟进—复查的闭环 |
| 销售人员讲健康 | 医生、健康管理师、养老管家提供专业解释 |
| 送一堆权益 | 用真实场景解释“权益何时被调用” |
| 只讲疾病风险 | 讲家庭医疗、就医、照护、养老的确定性 |
| 当场成交为目标 | 激活服务、建立档案、后续家庭经营为目标 |
| 用户是被销售对象 | 用户是会员、家庭服务的长期使用者 |

一句话说：

> 平安真正要卖的，不是“筛查后你可能有病”，而是“未来你和家人有事时，平安能把事情办下来”。

---

# 三、F端：平安如何把健康服务叠加到保险中

F端指集团金融客户，最主要是寿险、健康险、产险、银行客户。

平安健康对F端的公开表述是三类协同方式：

1. **保险+医养会员**
2. **医疗理赔协同**
3. **医健权益服务**

其官方表述为：通过“产品融合、权益采购、增值服务”等模式，为不同金融客户设计医疗健康养老服务组合，以帮助金融主业获客、黏客和二次转化。[平安健康业务介绍](https://www.jk.cn/businessIntroduction?bizMobilePage=businessModel)

---

## 1. “保险+医养会员”：让服务成为保单的会员资格

这是最适合高客单寿险、年金险和财富类保单的形式。

客户购买一定门槛的保单后，不是简单获赠几次问诊，而是获得某一级别的：

- 家庭医生；
- 健康档案；
- 专家咨询；
- 门诊／住院协助；
- 重疾专案管理；
- 体检或健康检测；
- 家庭成员共享服务；
- 居家养老或高品质养老服务资格。

### 具体案例：平安臻享RUN

平安人寿的“臻享RUN健康服务计划”是一个较典型的保单服务分层案例。公开服务手册显示，它将服务组织为“**1个医生 + 3类服务**”，并按产品、保费和服务等级提供不同服务；较高等级可包含家庭医生、私家医生、门诊预约协助、陪诊、特色体检、重疾专案管理等。[2023版《平安臻享健康服务计划服务手册》](https://cdn.life.pingan.com/ilifecore/common/202312110942d0w00ql6ktjf.pdf)

其中可被客户感知的具体权益包括：

| 权益 | 用户真正买到的价值 |
|---|---|
| 家庭医生 | 小病咨询、分诊、长期健康咨询 |
| 私家医生 | 更高规格的音视频／图文咨询与就医建议 |
| 门诊预约协助 | 降低挂号和找科室的难度 |
| 陪诊 | 降低老人、重疾患者线下就医的执行成本 |
| 住院安排协助 | 重疾时帮助连接医院与住院资源 |
| 国内／海外二次诊疗意见 | 复杂疾病时增加诊疗决策把握 |
| 重疾专案管理 | 从诊断到治疗、康复、心理和营养支持 |
| 体检及健康检测 | 从“发现风险”转入后续管理 |
| 家庭版服务 | 将个人保单价值变成全家权益 |

这类设计有一个很重要的销售技巧：

> **不把权益讲成赠品，而是讲成家庭医疗服务会员制。**

例如，销售不应该说“这张保单送你家庭医生”，而应该说：

> “这份保障在缴费期内，让你和家人有一个可长期调用的医疗入口。体检异常、父母看病、孩子夜间发烧、重大疾病就医，这些都不是你一个人去找资源。”

---

## 2. “医疗理赔协同”：把最有感知的服务放在出险时

保险最难让客户感受到价值，是因为它通常在出险前“看不见”。

平安的做法是把服务嵌进理赔前和理赔中：

- 线上家庭医生咨询；
- 导诊和医院网络指引；
- 门诊、住院协助；
- 理赔资料与流程协同；
- 健康管理和后续复诊；
- 对重疾客户的专项管理。

这才是健康权益最能建立口碑的环节：不是投保现场，而是客户真正需要就医时。

平安健康披露，2024年家庭医生服务了约209万相关模式保单客户，并强调其作用包括线上咨询、线下就医网络指引和健康管理。[平安健康医险协同说明](https://www.yicai.com/news/102508678.html)

---

## 3. “保险+居家养老”：用父母养老需求拉升高客单

这是平安最值得富德研究的一种打法。

它抓住的不是“用户怕生病”，而是中年子女非常具体的焦虑：

- 父母独居，突发情况谁响应？
- 去医院谁陪？
- 出院之后谁照护？
- 家里如何适老化？
- 不在同城，如何确认父母安全？
- 真需要养老机构时，谁来筛选和协调？

平安居家养老的公开服务框架包含医、食、住、行、财、康、养、乐、护、安等十类场景，并通过智能管家、生活管家和医生管家承接服务。[平安人寿居家养老介绍](https://life.pingan.com/next/news/detail?id=ef706b36-a0c1-48d5-a019-7fb2863f602d)

### 一个公开的资格示例

平安人寿在地方保险行业协会公开的居家养老说明中，曾列举一套资格门槛：

- 单个销售周期内，终身寿险或终身年金类保单总保费超过40万元；
- 且当年购买的所有保单总保费超过100万元；
- 达标客户可获得居家养老服务权益。

该口径明确说明，具体资格、地区和产品规则可能调整，因此只能作为历史案例，而不是当前通用投保条件。[青岛市保险行业协会转载的平安人寿居家养老介绍](https://www.iaqd.org.cn/news-detail.html?id=3698)

其附带服务通常包括：

- 医生管家；
- 慢病防控；
- 重疾专案管理；
- 健康服务；
- 居家养老咨询；
- 平安管家平台会员资格；
- 管家协助对接居家养老服务。

这里真正促成高价保单的不是“送一次上门服务”，而是：

> 用一张长期保单，换取父母未来数年甚至更长周期内进入一个养老服务网络的资格。

但必须注意：此类服务通常属于保单附加服务，并非保险合同中的保险责任；服务内容和规则可能调整。平安近期公开说明也明确了这一点。[“平安居家”服务说明](https://www.pa18.com/official/strategyDetail/28164504)

# 四、平安现场活动的理想销售流程

公开资料不会披露具体话术、单场转化率和内部SOP；但结合其产品体系、活动资料和代理人定位，可以把实际逻辑拆成以下链路。

## 阶段1：分层邀约，而不是泛邀约

客户标签通常围绕：

- 是否已有保单；
- 家庭生命周期：新婚、育儿、中年、临近退休；
- 是否有父母异地养老需求；
- 是否有体检异常、慢病、重疾历史；
- 资产和年缴保费能力；
- 是否为企业主、HR或高价值金融客户；
- 已拥有但未使用哪些服务权益。

高价值客户邀约的主题也不同：

| 客群 | 活动主题 |
|---|---|
| 育儿家庭 | 少儿健康、专科资源、家庭医生 |
| 中年客户 | 慢病、重疾就医、父母养老 |
| 高净值客户 | 高品质医疗、海外二诊、康养和传承 |
| 银行客户 | 健康财富、养老规划、家族照护 |
| 老年客户及子女 | 居家安全、慢病、陪诊、照护 |

重点是：**健康检测只是邀约钩子；家庭议题才是成交议题。**

---

## 阶段2：现场先体验“服务如何发生”

一个更成熟的现场，不是只摆设备，而应有四个连续体验：

1. **测评／筛查**  
   眼底、心电、血压、体成分、认知或跌倒风险等。

2. **专业解读**  
   由医生或健康管理师解释风险边界，避免“仪器一测必有病”的销售化表达。

3. **服务路径展示**  
   不只告诉客户“有风险”，而是明确：  
   - 谁会回访；  
   - 可线上找谁；  
   - 需线下时去哪；  
   - 父母不便出门时怎么办；  
   - 重疾或住院时谁协助。

4. **保单权益匹配**  
   不是先讲产品，而是先区分客户已拥有、可激活和需要补足的权益。

客户在现场最应感受到的，不是恐惧，而是：

> “原来我遇到这件事以后，服务链路是这样运行的。”

---

## 阶段3：从“个人检测报告”转向“家庭服务方案”

这一步是普通健康营销与高客单保险销售的分水岭。

### 低客单话术

> 你的指标有风险，建议买一份重疾险／医疗险。

### 高价值服务话术

> 今天的报告只是一个信号。更重要的是，您家里谁负责父母养老、谁有慢病风险、孩子就医谁来安排、未来需要住院谁协调？这份方案不是只赔钱，而是为家庭配置医疗和养老的服务入口。

这会把讨论从“我有没有病”，变成：

- 家庭保障缺口；
- 家庭健康责任；
- 父母养老责任；
- 医疗资源可得性；
- 长期财富和传承安排。

---

## 阶段4：成交后要立刻“激活权益”

这是富德场景最值得补的一步。

如果活动结束就让客户回家，保单权益停留在宣传册上，用户仍会觉得这是销售赠品。

平安式的理想闭环应是投保后马上完成：

- 下载／登录平安金管家或平安好医生；
- 绑定保单和权益人；
- 建立家庭健康档案；
- 添加父母、配偶、子女；
- 做一次家庭医生首访；
- 预约一次可立刻使用的健康服务；
- 给客户展示服务入口和服务时效；
- 由代理人做首次权益回访。

这样用户不是“听说我有权益”，而是已经用过一次。

---

## 阶段5：用服务使用创造续保、加保与转介绍

真正有效的增长飞轮是：

> 活动邀约 → 服务体验 → 投保 → 权益激活 → 服务使用 → 理赔／就医／养老关键时刻履约 → 客户认可 → 加保、续保、转介绍。

平安的逻辑是通过医疗养老服务提升金融业务获客、黏客和二次转化，而不是把健康服务当成一次性的签单礼。[平安健康对F端模式的说明](https://www.cnfin.com/yw-lb/detail/20240321/4025758_1.html)

# 六、对富德当前模式的直接启发

## 1. 不要把“异常发现率”作为活动成功指标

因为这会让活动天然走向焦虑营销，也很难建立长期信任。

更好的指标应是：

- 到场客户中完成健康档案比例；
- 家庭成员绑定率；
- 服务权益激活率；
- 首次家庭医生咨询率；
- 筛查异常者的专业复核率；
- 后续就医服务使用率；
- 30／90天客户回访满意度；
- 加保、续保和转介绍率。

---

## 2. 检测之后必须有“医学解释 + 服务承接”

一场筛查若没有后续，用户只留下焦虑；若由销售解释，用户会觉得是销售套路。

应设置明确的分工：

- 医疗人员：解释筛查结果、风险边界和就医建议；
- 健康管理师：建立档案、安排跟踪；
- 服务管家：协助预约和服务兑现；
- 保险顾问：最后才做家庭保障缺口与服务方案沟通。

---

## 3. 把“保险附赠服务”升级为“分层会员权益”

不要说“买X送Y次服务”，而要分层表达：

| 低层权益 | 中层权益 | 高层权益 |
|---|---|---|
| 在线问诊、健康测评 | 家庭医生、体检、慢病管理、就医协助 | 重疾专案、陪诊、养老管家、居家照护、高端医疗资源 |
| 解决日常问题 | 解决健康管理问题 | 解决家庭重大医疗与养老问题 |

用户才能理解：保费更高，不只是保额更高，**服务的响应能力、资源层级和家庭覆盖范围也不同。**

---

## 4. 以“家庭”为单位，不要只面对中老年本人

中老年活动的真实购买决策者往往是子女；而子女的真实痛点通常是：

- 不在父母身边；
- 不会判断医疗信息；
- 无法陪诊；
- 担心突发状况；
- 不知道如何配置养老服务。

所以最有价值的活动设计，是让客户带子女参加，或通过视频、线上家庭服务方案让子女参与后续决策。

---

## 5. 先卖“服务确定性”，再卖“健康焦虑”

最可迁移的平安思路是：

> 用户未必会因为知道自己有风险而信任保险公司；  
> 但会因为相信“关键时刻有人能把事情办下来”，而认可保险与健康服务的长期价值。

这也是平安能把健康、医疗、养老服务放进高保费寿险和年金险中的核心原因。
