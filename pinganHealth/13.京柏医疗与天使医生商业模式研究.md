## 一句话结论

> 京柏医疗/天使医生用**"硬件设备起家 + 医院深度绑定 + 循证医学包装"**走出了一条与长轻、平安健康完全不同的路径：它不做C端流量生意，而是把自己嵌入到公立医院的产科诊疗流程里，靠"院内院外一体化"的孕产专病管理系统，成为医院提升专科能力、患者提升就医体验的基础设施。这是本组对标研究里**唯一一个既有真实临床数据、又有真实医院合作规模、且商业模式清晰可验证**的平台，值得作为富德联好"专病+设备+医院协同"路径的正面样板深入研究。

# 二、发展脉络：从设备公司到"智慧妇幼"平台

## 1. 转型契机（创始人易辉自述，见 HIT专家网专访）

- 2009年京柏陷入经营困境（年销售额仅830万元），易辉临危受命；
- 2013年判断"医疗信息设备行业出了问题"，认为传统硬件销售模式难以为继，"不转型只有死路一条"；
- 早期互联网化尝试失败的教训是"没有深入了解临床需求，只是披上互联网的外衣，并不能解决实际问题"；
- 战略哲学："顺着趋势提前一点点布局，永远不会出大事情"——主张跟随趋势渐进转型而非激进颠覆。

## 2. 转型后的核心逻辑

> **把互联网定义为工具而非目的，核心是解决"医疗数据孤岛"问题，实现医生、患者、医院三方数据互联互通。**

具体做法是把三个要素整合在一起：

1. 院外移动医疗终端（孕妇端/医生端App）；
2. 医疗硬件设备的物联网化（胎心监护仪、血压计等接入云端）；
3. 医院内部信息系统对接（与医院HIS/产科系统打通）。

# 三、产品与服务体系

## 1. 平台定位

> "多学科联合的院内院外一体化孕产健康管理平台"，围绕"备孕—孕期—月子—产后—育儿"全生命周期场景。

## 2. 核心产品模块

| 模块 | 功能 |
|---|---|
| 医院端"围产期健康管理中心" | 部署在医院内部，对接HIS系统，供医生管理孕产妇档案、多学科会诊协调 |
| 孕妇移动端 | 建档、产检提醒、胎心监护数据查看、专属健康管家沟通、互联网医院问诊 |
| 医生移动端（天使医生Pro/布谷医生） | 远程查看患者监测数据、异常预警处理、多学科协同 |
| 智能可穿戴/家用设备接入 | 远程胎心监护仪、体重/血压/血糖监测设备等，实现居家7×24小时体征监测 |
| 专项管理系统 | 体重营养管理、妊娠糖尿病管理、远程胎心监护、妊高症（妊娠期高血压）管理等专病模块 |

## 3. 服务模式："院内院外一体化"双层架构

- **院内**：一站式产检全流程服务，专属健康管家协调产科、营养、心理等多学科专家会诊，与110+三甲医院深度驻点合作；
- **院外**：通过医疗级设备实现居家实时体征监测，数据异常时触发预警，联动院内医生及早介入。

## 4. 循证/数据资产（官方披露）

- 累计解读胎心监护报告 **1600万份**；
- 与全国 **600余家公立医院**、**110+三甲医院**建立深度合作；
- 聚集近 **2000名妇产科医生**资源；
- 2024-2026年披露与清华大学、北京大学等机构合作，推进科研成果转化（具体论文/研究成果未见公开检索到）。

这是长轻完全不具备的部分：**天使医生的"循证"是可以对应到具体医院、具体设备、具体数据量的**，而不是自造理论话术。

# 四、商业模式：B2B2C，医院是核心渠道和真正客户

## 1. 合作路径

> **京柏医疗（设备+系统供应商）→ 医院（采购方/推广渠道）→ 医生（使用者）→ 孕产妇（终端用户）**

- 医院采购天使医生的信息化系统和硬件设备，作为提升产科学科能力、改善患者服务体验的基础设施；
- 医院通过自身产科门诊/病房渠道向孕产妇推广App使用，天使医生本身几乎不做C端广告获客；
- 医生是实际的日常使用者，通过App/Pro端管理患者、处理预警；
- 孕产妇是终端体验者，多数情况下由医院导入，而非自主下载付费。

## 2. 收入来源（推断，公开信息未披露具体收费明细）

1. 向医院销售/部署智能硬件设备（胎心监护仪等，京柏医疗的传统主业）；
2. 向医院销售/授权信息化系统（围产期健康管理中心的软件许可、维护服务费）；
3. 科室级/项目级的专科能力建设合作（如"智慧妇幼专科能力建设解决方案"）；
4. 可能存在的VIP产检、居家监测包等C端付费增值服务（未见具体定价公开，需要进一步实地/渠道调研验证）；
5. 未来规划方向：对接挂号预约、微信支付等增值服务闭环（据早期动脉网报道的产品路线图）。

## 3. 与长轻、平安健康的商业模式对比

| 维度 | 京柏医疗/天使医生 | 长轻营养食疗 | 平安健康 |
|---|---|---|---|
| 起家路径 | 硬件设备公司转型（1998年起） | 2021年直接以直播/私域切入 | 互联网问诊平台转型保险生态 |
| 核心客户 | 医院（B端为主） | C端个人 | F端保险+B端企业+C端个人 |
| 获客方式 | 医院渠道导入，几乎不做C端广告 | 直播间+私域话术营销 | 保险渠道、企业渠道、自然流量 |
| 数据与循证 | 真实设备数据、千万级监护报告、医院背书 | 自创理论话术，无第三方验证 | 依托实体医疗网络专科资源 |
| 商业化压力来源 | 医院采购预算周期、设备迭代 | 直播间转化率、私域信任 | 保险续保率、企业采购续约 |
| 用户直接付费意愿 | 低（多为医院买单或保险/项目导入） | 极高（一次性大额自费） | 中等（问诊、药品高，泛管理低） |

# 五、公开舆论与媒体评价

## 1. 正面信源（专业媒体/行业媒体）

- **动脉网**《天使医生：让400余家医院爱上的孕产期健康管理产品》：早期（约2016年）对其B2B2C模式、医院覆盖规模的行业报道，是判断其真实性和落地能力的重要依据；
- **HIT专家网**对创始人易辉的深度专访：披露了公司转型历程、战略逻辑，属于医疗信息化垂直媒体的专业访谈，可信度较高；
- **中华网**《天使医生：数据与循证双轮驱动，让孕产健康管理走向系统化》（2026年）：披露了1600万份胎心监护报告解读量、与清华北大科研合作等最新进展，是近期口径的重要参照。

## 2. 值得注意的信息不一致

- 不同时间的通稿对"合作医院数量"（400余家→600余家）、"服务用户规模"（230万+→240万+）口径存在明显变化，属于正常的业务增长表述，但缺乏第三方审计或统一统计口径，建议在对标时仅作为**方向性参考**而非精确数字；
- 公开渠道未检索到融资轮次超过2016年A+轮的进一步披露，也未检索到该公司是否已启动上市辅导、被并购或其他重大资本动作的信息，说明其近十年发展可能更依赖内生收入而非持续融资驱动，也可能存在资本关注度下降的风险，需要留意后续是否有新的经营/财务信息可交叉验证。

## 3. 争议与投诉

与长轻不同，公开检索未发现天使医生/京柏医疗有集中性消费者投诉（黑猫投诉等平台未见规模性案例），这与其B2B2C模式高度相关——**孕产妇很少直接为App本身付费或产生退款纠纷，投诉更可能流向承担产检费用的医院本身，而不会归因到系统供应商**。这也是B2B2C模式相较C端直销模式在舆情风险上的结构性优势，但同时意味着**该模式的真实用户体验、满意度缺乏独立第三方渠道验证**，公开信息基本来自企业自述和合作方背书。

# 六、与平安健康"天使医生"条目的交叉印证

本对标研究此前在 [[14.平安健康与天使医生商业模式对比]] 中已对天使医生做过用户价值层面的分析，核心结论与本次企业侧调研互相印证：

- 天使医生的典型渠道确实是"医院端（合作/建档/项目采购）→ 医生端（管理患者）→ 用户端（医院导入为主，自购为辅）"，与本次对官网、创始人访谈信息的调研完全一致；
- 孕产家庭购买的核心价值是"提前发现风险""持续监测""异常后有人处理""安心感"四层需求，这与京柏医疗"数据与循证双轮驱动"的战略表述相互印证——**其真正壁垒不是App本身，而是设备数据连续性 + 医院专科协同关系**。

# 七、对富德联好的启示

## 1. 正面样板：专病+设备+医院协同是可复制的路径

天使医生证明了一条与长轻、纯C端问诊完全不同、且更稳健的路径：

> **选择一个高风险、高焦虑、诊疗路径清晰的专病场景（孕产） → 用硬件设备把医院的监测能力延伸到家庭 → 用医院驻点合作而非广告获客 → 用真实数据积累形成循证壁垒。**

这与此前报告对富德的建议高度一致（见 [[14.平安健康与天使医生商业模式对比]] 第十二节），本次企业侧调研进一步验证了该路径在**十年时间尺度上是可持续、可规模化**的（京柏医疗从1998年设备公司到现在，走了近30年）。

## 2. 富德可借鉴的具体做法

1. **不要一开始就做纯C端App**，优先寻找1-2家专病领域重点医院/科室共建试点（如肿瘤康复、术后康复、居家护理场景），把系统和设备嵌入到医院既有诊疗流程里；
2. **用设备数据而非话术建立信任**：投入真实的监测硬件/数据能力，即使规模不如互联网大厂，"能拿出多少份监测报告、多少家医院合作"本身就是最有说服力的循证资产；
3. **收入结构优先绑定B端（医院/保险/企业）而非C端一次性收费**，降低对营销转化率的依赖，天然规避长轻式的投诉和监管风险；
4. **保持渐进式转型节奏**：京柏"顺势提前一点点布局"的策略值得参考——富德不必追求一步做成平安级别的大生态，可以先在1-2个专病场景把"设备+医院+数据"模式验证扎实，再横向复制。

## 3. 需要进一步补充调研的空白

- 天使医生具体的C端收费项目（VIP产检、居家监测包等）定价与转化率，需要通过渠道访谈或实地了解App内购买页面获取，公开信息不足；
- 京柏医疗近5年（2019年至今）的财务健康度、是否有新融资或被并购动向，公开检索未见披露，建议后续通过企查查/天眼查等企业信息平台做工商变更、股权穿透的补充核查；
- 医院端真实采购价格和合作条款（分成模式、买断模式、SaaS订阅模式）未见公开披露，是判断其是否可复制到富德体系的关键信息缺口。

## 最终判断

> 天使医生的用户（孕产家庭）买的是"对高风险孕产过程的连续监测、提前预警和及时干预"；而京柏医疗真正的客户（医院）买的是"用信息化和设备能力提升产科专科水平、改善患者体验、建立学科竞争力"。这是一套**以医院为核心杠杆、以设备数据为信任基础**的B2B2C模式，是本组已调研平台中商业逻辑最清晰、可持续性证据最充分的一个，值得作为富德联好"专病化+医院协同"路径的正面对标案例长期跟踪。
